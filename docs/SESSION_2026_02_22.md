## What We Did Today

### 1. Fixed Pinch-to-Zoom on Image

**Problem:** When user touched the image to zoom/pan, the entire page would scroll instead.

**Solution:** 
- Added `NotificationListener<ScrollNotification>` around `SingleChildScrollView`
- Track touch state with `_isImageTouched` flag
- When image area is touched, block parent scrolling
- When finger lifts, re-enable scrolling

**Files:** `mobile/lib/pages/camera_page.dart`

---

### 2. Created 4-Point Draggable Crescent Guide

**Problem:** Old crescent guide was purely visual, not customizable.

**Solution:** Built `DraggableCrescentGuide` widget with:
- **4 control points:** L (left), R (right), T (top curve), B (bottom curve)
- Horizontal "smile" crescent shape using quadratic Bezier curves
- Each point draggable by touch
- Shape updates in real-time as points move

**Key Code (Bezier path):**
```dart
path.moveTo(leftPoint.dx, leftPoint.dy);
path.quadraticBezierTo(topControl.dx, topControl.dy, rightPoint.dx, rightPoint.dy);
path.quadraticBezierTo(bottomControl.dx, bottomControl.dy, leftPoint.dx, leftPoint.dy);
```

**Files:** `mobile/lib/widgets/conjunctiva_guide.dart`

---

### 3. Fixed Control Point Dragging Issues

**Problems:**
1. Dragging a point would move the image instead
2. Points would drift away from finger
3. Touch target too small

**Solutions:**
1. Added `_draggingPoint` state to track which point is active
2. Fixed stale closure bug - now reads current position on each `onPanUpdate`
3. Made touch area 60px (invisible) while visual button stays 26px
4. Used `HitTestBehavior.opaque` to claim all touches

**Code snippet:**
```dart
Widget _buildControlPoint(int index, Offset position, String label) {
  const double visualSize = 26;
  const double touchSize = 60;
  
  return Positioned(
    left: position.dx - touchSize / 2,
    top: position.dy - touchSize / 2,
    child: GestureDetector(
      behavior: HitTestBehavior.opaque,
      onPanStart: (_) => setState(() => _draggingPoint = index),
      onPanUpdate: (details) {
        if (_draggingPoint != index) return;
        _updatePointFromScreenPos(index, position + details.delta);
      },
      // ...
    ),
  );
}
```

### 4. Added Internal Padding for Hit Testing

**Problem:** Control points could go outside widget bounds, breaking touch detection.

**Solution:**
- Added `_padding = 35.0` inside `DraggableCrescentGuide`
- Widget's `SizedBox` now = inner dimensions + 2×padding
- All control points guaranteed to stay in hit-testable area

---

### 5. Reset Button Now Resets Everything

**Problem:** Reset only reset position/scale, not crescent shape or image zoom.

**Solution:** `_resetCropper()` now resets:
- `_guideOffset` (position)
- `_guideScale` (size)
- `_guidePoints` (crescent shape via `_crescentGuideKey.currentState?.reset()`)
- `_transformationController` (image zoom/pan)

---

### 6. Control Points Stay Within Bounds

**Problem:** B (bottom) point could go below the cropper box border.

**Solution:** Adjusted clamping limits:
- T/B points: -35% to 135% vertically (relative to inner height)
- L/R points: -10% to 110% horizontally (relative to inner width)
- All points clamped to stay within padded widget bounds

## Crescent Guide Architecture

```
DraggableCrescentGuide (StatefulWidget)
├── SizedBox (width + 2*padding, height + 2*padding)
│   └── Stack (clipBehavior: Clip.none)
│       ├── CustomPaint (_DraggableCrescentPainter)
│       │   └── Draws Bezier crescent from 4 points
│       ├── GestureDetector (body - for moving whole guide)
│       └── 4× _buildControlPoint (L, R, T, B)
│           └── GestureDetector (HitTestBehavior.opaque)
│               └── Container (60px touch, 26px visual)

Points stored as ratios (0-1) of inner dimensions
→ Scale proportionally when guide resizes
```
